# 交接元信息契约 v1.0

文档使用 UTF-8，第一行为独立的 `---`，以另一个独立的 `---` 结束 YAML 1.2 mapping，随后是非空 Markdown 正文。不要把整份文档包在代码围栏里。键不得重复。

| 字段 | 必需类型与含义 |
| --- | --- |
| `title` | 非空字符串，交接主题 |
| `type` | 字符串，固定为 `session-handoff` |
| `schema_version` | 带单引号或双引号的字符串，当前为 `'1.0'` |
| `created` | 带引号的真实 `YYYY-MM-DD` 日期字符串，首次生成日期 |
| `updated` | 带引号的真实 `YYYY-MM-DD` 日期字符串，实际修订日期，不早于 created |
| `status` | 非空字符串，描述被交接工作的状态，例如 planning、in-progress、blocked、completed；不是执行授权 |
| `tags` | 至少一个非空字符串的 YAML 列表 |
| `language` | 非空语言标识字符串，例如 zh-CN、en |
| `source_agent` | 非空字符串或 YAML `null`；来源 agent 未知时为 null |
| `source_workspace` | 非空字符串或 null；来源环境未知时为 null |
| `target_workspace` | 非空字符串或 null；目标未指定时为 null |

所有字段均必须出现；“未知”不等于空字符串，不要把 `null` 写成带引号的 `'null'`。默认使用字面量和列表，避免自定义 YAML 标签、锚点与别名，便于其他工具读取。可增加确实有用的分支、提交等字段，不携带秘密。v1.0 校验器容许额外字段，但不验证其业务含义。

标题、状态、标签、语言和路径应引用为字符串。Windows 路径优先用单引号，如 `'D:\work\demo'`；单引号值中出现 `'` 时写成 `''`。不要对包含秘密的输入仅加引号后原样输出；应先省略秘密值。不能机械替换未转义的标题进 YAML 模板。

日期按用户当地日期填写；未知时先取得日期，不从模板、旧文档或示例复制一个当前日期。更新时读取原版保留 created，更新 updated、status 和正文中的变化；若原 created 无效或未知，说明问题并取得依据，不静默重置。

元信息和正文必须一致：completed 不能掩盖未完成验收；target_workspace 不能把建议目录当成已确定目标。来源路径仅说明源环境位置，不证明接收方能访问它。

校验器覆盖语法、字段类型、引号、日历日期、日期顺序、正文存在，以及提供原版时 created 不变、updated 不回退；不会证明语言、状态、工作空间、事实、授权或脱敏正确，也不会证明 updated 就是实际修订日期。
